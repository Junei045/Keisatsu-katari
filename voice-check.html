自然な声を増やす方法

Windows の場合
Nanami・Keita といった自然な音声は、Microsoft Edge でしか出てこないことがあります。まず Edge でこのページを開き、一覧が変わるか確かめてください。

入っていない場合は、Windows の「設定 → 時刻と言語 → 音声認識 → 音声を管理 → 音声の追加」で日本語の音声を追加できます。
iPad・iPhone の場合
「設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語」で、Kyoko・Otoya の「強化」または「プレミアム」を選んでダウンロードすると、はっきり自然になります。標準のままだと機械的です。
Android の場合
「設定 → システム → 言語と入力 → テキスト読み上げ」で Google の音声サービスを選び、日本語の音声データを更新してください。
それでも足りないとき
合成音には限界があります。人の声で audio/01.mp3〜20.mp3 を録音し、index.html の USE_RECORDED を true にするのが、いちばん確実です。
